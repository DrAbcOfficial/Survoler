# Survoler

An Android app for quick document previews. Supported files are processed **entirely locally and offline**, with no uploads.

**For quick viewing only. Content, layout and rendering accuracy or completeness are not guaranteed. Previews do not replace the original document or a dedicated reader.**

## Supported Formats

| Type | Extensions |
| --- | --- |
| Word | `doc`, `docx`, `dot`, `dotx`, `wps`, `wpt` |
| Excel | `xls`, `xlsx`, `xlsm`, `xlt`, `xltm`, `xla`, `xlam`, `et`, `ett` |
| PowerPoint | `ppt`, `pptx`, `pptm`, `dps`, `dpt` |
| Other | `csv`, `pdf`, `ofd` |

Some formats support only compatible content or static previews. Macros and add-ins are never executed; independent OFD seals, signatures and annotations are skipped. See [format support and limitations](FORMAT_SUPPORT.md).

## Usage

Requires an ARM64 device running Android 6.0 or later. Select Survoler from your file manager's **Open With** menu to preview, navigate pages, zoom and copy extractable text. The app has no launcher entry.
